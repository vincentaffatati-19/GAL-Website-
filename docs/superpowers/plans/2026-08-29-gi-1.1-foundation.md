# GI-1.1 Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish Git-controlled Supabase migrations/tests for canonical facts, fact history, inferences, questions, and append-only consent governance without changing production.

**Architecture:** Add a new `supabase/` tree to the existing static-site repository. Implement governance catalogs first, then extend current profile facts additively, then add append-only provenance/question tables and tighten consent RLS. Use pgTAP-style SQL tests and synthetic auth/user fixtures.

**Tech Stack:** PostgreSQL 17, Supabase CLI/migrations, pgTAP SQL, RLS, Git.

**Spec:** `docs/superpowers/specs/2026-08-28-golfer-intelligence-data-model-v1.1-design.md`

## Global Constraints

- `gal_users.id` is the canonical golfer FK.
- `gal_profile_facts` remains one current row per `(user_id, fact_key, scope)`.
- History is append-only to normal golfer clients.
- Existing `source` and `source_category` remain during expand-and-contract migration.
- New facts/questions/events/models are catalog-governed.
- Consent history becomes select + append for normal golfers; prior rows cannot be updated/deleted.
- All new exposed golfer tables require RLS and ownership tests.
- No production migration is applied during implementation.

- [ ] **Step 5: Implement `gal_set_profile_fact` contract**

The function must:

1. resolve current authenticated GAL user unless explicitly invoked by a trusted server role;
2. validate the fact key exists and is active;
3. lock the current `(user_id,fact_key,scope)` row;
4. copy the prior row into history when a material prior row exists;
5. upsert the new current row;
6. preserve source/provenance fields;
7. return the current fact row ID.

Do not mark the function `SECURITY DEFINER` unless required and separately reviewed; prefer a trusted server transaction path if normal privileges suffice.
